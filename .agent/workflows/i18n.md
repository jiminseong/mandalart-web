# i18n Workflow & Status

This document tracks the internationalization (i18n) progress for the Mandalart & Health OS project.

## 1. Guidelines
- **Libraries**: `next-intl`
- **Files**: `messages/ko.json` (Source), `messages/en.json` (Target)
- **Convention**: Use nested keys namespace by feature (e.g., `health.timer.title`).

## 2. Health OS i18n Plan

### Phase 1: Core Workout Features (Priority 🚨)
Focus on the newly implemented Timer and Session logging features.

**Target Files:**
- `src/app/[locale]/health/workout/log/WorkoutTimer.tsx` (Rest Timer)
- `src/app/[locale]/health/workout/log/WorkoutSession.tsx` (Session Log)

**Tasks:**
- [ ] Extract strings from `WorkoutTimer.tsx` (e.g., "휴식 끝!", "사용자 설정")
- [ ] Extract strings from `WorkoutSession.tsx` (e.g., "세션 기록", "세트 추가")
- [ ] Update `messages/ko.json` with `health` namespace.
- [ ] Create/Update `messages/en.json`.
- [ ] Refactor components to use `useTranslations`.

### Phase 2: Dashboard & Goals
**Target Files:**
- `src/app/[locale]/health/page.tsx`
- `src/app/[locale]/health/goals/current/page.tsx`

**Tasks:**
- [ ] Identify hardcoded texts in Dashboard widgets.
- [ ] Dashboard specific keys (`health.dashboard`).

### Phase 3: Dynamic Content (Exercises)
- **Challenge**: Exercise names ("벤치프레스", "스쿼트") are currently hardcoded or DB data.
- **Strategy**: 
    - For static UI: Use `ko.json`.
    - For DB content: Add `name_en` column to Supabase tables or use a translation map.
