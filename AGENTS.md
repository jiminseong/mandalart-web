# Agents & Skills

This project uses custom skills for UI/UX design.

## Available Skills

### apple-ui-designer
iOS Human Interface Guidelines, native Apple feel - Redesign mobile app UI to feel unmistakably Apple-like with SF Pro typography, translucency, and system-like components.

**File:** `skills/apple-ui-designer/SKILL.md`

**Usage:**
```
$apple-ui-designer <request>
```

**Example:**
- `$apple-ui-designer 만다라트 메인 화면을 iOS 네이티브 스타일로 디자인해줘`
- `$apple-ui-designer 설정 페이지를 Apple HIG 가이드라인에 맞게 수정해줘`

## Design Philosophy

The apple-ui-designer skill follows these principles:
- Native over custom
- Subtle over expressive
- Calm, confident, and human
- "Feels obvious" rather than "looks fancy"
